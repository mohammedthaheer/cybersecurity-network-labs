# Cybersecurity & Network Security Labs

Hands-on Cisco networking and network security labs built using **Cisco Packet Tracer**.

This repository documents my practical work while developing my networking and cybersecurity skills, with a focus on network fundamentals, routing, switching, network services, and security concepts.

## 🎯 Objectives

- Build and troubleshoot practical network topologies
- Strengthen networking fundamentals through hands-on configuration
- Understand how routing and switching operate in real-world network environments
- Practice network segmentation and access control
- Develop a foundation for network security and SOC-related work

## 📂 Lab Categories

### 01. Network Fundamentals
Basic networking and routing configurations used to build a foundation for more advanced labs.

### 02. Routing
Hands-on practice with static and dynamic routing protocols, including:

- Static Routing
- OSPF
- EIGRP
- RIP
- Default Routes

### 03. Switching
Labs covering Layer 2 and Layer 3 switching concepts, including:

- VLANs
- Inter-VLAN Routing
- SVI
- STP
- RSTP
- VTP

### 04. Network Services
Practical configurations involving common network services:

- DHCP
- DNS
- NAT

### 05. Network Security
Labs focused on controlling and securing network access:

- Standard ACLs
- Extended ACLs
- Named ACLs
- Numbered ACLs
- Switch Port Security
- Network Segmentation

### 06. High Availability
Labs exploring network redundancy and gateway availability:

- HSRP
